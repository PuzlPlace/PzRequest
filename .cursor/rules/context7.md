# Context7 MCP

Use **Context7** quando a tarefa envolver documentação ou exemplos de bibliotecas/frameworks/APIs.

**Quando:** Validação Laravel, Vue, TypeScript, libs npm, configuração de APIs, assinaturas/opções de libs.

**Como:** `resolve-library-id` + `query-docs` para obter docs/exemplos atualizados. Preferir Context7 em vez de conhecimento de treinamento para libs que evoluem.
